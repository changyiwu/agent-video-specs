# 影片類型規範 #02：教學影片

> 給 agent 用的硬規範。看完應該能直接動工。
> 若使用者沒指定，預設依本文件執行；若衝突，以使用者明示為準。
> 同時參考 [01-活動紀錄影片.md](./01-活動紀錄影片.md) 中通用的渲染管線。

---

## 1. 定位

**用途**：把一個學科概念，用 3–8 分鐘的動畫影片完整講清楚，學生看完能複述、能應用。
**典型場景**：國小、國中、高中學科教學（數學優先），可延伸到自然、社會。
**核心三元素**：① **SOIL 教學脈絡**（先教學判斷再呈現）② **HTML/CSS/SVG 視覺化動畫** ③ **Edge-TTS 旁白**（免費、台灣腔）。

**和其他類型的差別**
- 不是活動紀錄片（不重現情緒，而是建構知識）
- 不是廣告片（無 CTA）
- **每頁有教學任務**，不是「漂亮的內容容器」
- **動畫服務理解**，不是炫技

## 2. 三層架構

```
┌─────────────────────────────────────────────┐
│ Layer 1：教學內容 — SOIL 六引擎               │
│   概念定位 → 脈絡 → 頁面 → 認知 → 風格 → 合成 │
├─────────────────────────────────────────────┤
│ Layer 2：視覺呈現 — HTML/CSS/SVG + KaTeX    │
│   SVG 動畫、step-by-step 揭露、視覺化推理     │
├─────────────────────────────────────────────┤
│ Layer 3：聲音 — Edge-TTS                    │
│   zh-TW-HsiaoChenNeural（預設）/ YunJhe     │
└─────────────────────────────────────────────┘
```

**順序不能反**：先想清楚教什麼（SOIL 1-3），再決定怎麼呈現（4-6），最後才處理聲音。

---

## 3. SOIL 工作流要點（必跑前三引擎再動工）

### 引擎 1｜概念定位稿
產出：總概念、3 子概念、3 常見誤解、帶走一句話、最小事實包、投影片 vs 旁白分配表。
**不能跳過**：直接做投影片會塞太多。

### 引擎 2｜脈絡定位稿
固定三段式：**引起動機（15–20%）→ 維持注意（60–70%）→ 喚起行動（15–20%）**。
每段標明：教學目的、入口、出口、建議頁數。

### 引擎 3｜頁面架構表
每頁四欄：**# / 時間 / 標題 / 頁面角色 / 唯一主重點 / 動畫描述 / ★關鍵**
頁面角色不超過 1/4 是同一種（避免單調）。
**影片預設從頭播到尾**：不要做「按暫停自己算」加倒數的練習頁，除非使用者要求。想放練習，就做成直接講解的例題（GOTCHAS A-5）。

### 引擎 4-6 簡化版
- 4：每頁用六認知詞檢查（降雜訊、區塊化、增資訊、結構化、順脈絡、步驟化）
- 5：用本文件第 4 節風格規範（不用每次重新定）
- 6：合成 HTML（不是 pptx，因為我們要動畫）

## 4. 視覺設計系統（林長揚 30 原則 × SOIL 落地）

### 4.1 字體
**主字體**：**源石黑體 GenSekiGothic2TW**（粗圓感，符合林長揚 #7「字體選黑體粗體」）

| 字重 | 用途 |
|------|------|
| **H (900)** | 標題、強調數字、關鍵字 |
| **B (700)** | 副標、章節編號、字幕 |
| **M (500)** | 內文、註解 |

**嵌入方式**：
```css
@font-face {
  font-family: 'GenSeki TW';
  src: url('assets/fonts/GenSekiGothic2TW-H.otf') format('opentype');
  font-weight: 900;
  font-display: block;
}
/* 同樣方法載入 B (700) 與 M (500) */
```

> 字檔位置：**影片專案自己的 `assets/fonts/`**。HyperFrames 不接受 `../` 跳出專案根目錄的路徑，所以不能共用 repo 根目錄那一份（GOTCHAS D-2）。新機器跑 `bash install/install_fonts.sh`（或 `python install/setup.py fonts`）會下載並複製進每個範本；fork 範本時連同 `assets/fonts/` 一起複製。上游來源：[ButTaiwan/genseki-font (GitHub)](https://github.com/ButTaiwan/genseki-font)。

### 4.2 字級階（林長揚 #1：55/34/21/13 黃金比例）
在 1920×1080 畫布同比放大：

| Token | 大小 | 用途 |
|-------|------|------|
| `--fs-hero` | **168–260px** | 封面、結語金句、巨大強調數字 |
| `--fs-title` | **120–140px** | 頁面主標題 |
| `--fs-sub` | **80–96px** | 副標題、章節標題 |
| `--fs-body` | **48–64px** | 內文、定義 |
| `--fs-note` | **24–32px** | 註解、章節編號、字幕 |

**行距 = 字大小的 50–75%**（line-height 1.15–1.45）

### 4.3 配色
| HEX | 名稱 | 用途 |
|------|------|------|
| `#FAF7EE` | paper（米黃）| 內容頁背景 |
| `#F2EDDC` | paper-2 | 卡片底色 |
| `#1A1A1A` | ink | 文字主色、封面/結語背景 |
| `#0E7C7B` | teal | **主強調色**（概念名詞、第一強調）|
| `#E36414` | coral | **副強調色**（重點數字、第二強調）|
| `#C8941F` | gold | 第三色，只用於微點綴 |

**林長揚 #25：強調色 1–2 種**。teal + coral 兩主色，gold 只在必要時用，不超過兩處。
gold 放在米黃底（paper／paper-2）上的小字對比只有約 2.3:1，`check` 會報不足 3:1：gold 只用在黑底或大字，米黃底上的小符號改用深一階的 `#A37712`。
coral `#E36414` 放在 paper-2 卡片上當大字，對比是 2.94:1，也會被 `check` 報不足 3:1；卡片上有大量橘字的影片改用 `#E06314`（肉眼看不出差別）。
**同一概念全片同一色**（例：因數家族一律 teal、倍數家族一律 coral），學生看顏色就知道在講哪一類。

### 4.4 版面（林長揚 #10「版面留白」反向應用）
**這類教學影片的留白要少**（與紀錄片相反）：
- padding：56px 80px 120px（上 / 左右 / 下）
- 內容區應**填滿至少 80% 畫布**
- 不要為了「美觀」留大片空白
- **林長揚 #14：元素對齊**：所有字卡、SVG 對齊基準線

### 4.5 必備 UI 元件
- **章節 chip**（左上）：`<span style="background:teal;color:white;padding:4px 12px">01</span> / 12 — 章節名`
- **進度條**（底部 5px teal）
- **字幕條**（底部，黑底白字，旁白逐句顯示）
- **黑色封面 + 黑色結語**（三明治結構，內容頁淺色）

## 5. 動畫規範

> 所有動畫寫在同一條 GSAP 時間軸上，由 [HyperFrames](https://github.com/heygen-com/hyperframes) 逐格算繪
> （見第 8 章、[GOTCHAS C／D 節](../GOTCHAS.md)）。畫面只能由時間決定：不用 CSS transition、`setTimeout`、`Math.random`。

### 5.1 動畫類型
| 類型 | 用途 | 實作 |
|------|------|------|
| **逐元素揭露** | 配對找因數、列出質數 | `tl.fromTo(el, {opacity:0}, {opacity:1}, S(n) + k*間隔)` 逐一排上時間軸 |
| **路徑繪製** | 因數樹、知識地圖連線 | SVG `pathLength="100"` + `stroke-dasharray:100`，tween `strokeDashoffset` 100 → 0 |
| **形狀重組** | 24 人分組（2×12 → 3×8 → 4×6） | 三種排法預先排好、疊在同一位置，用淡入淡出切換 |
| **數字爆出** | 因數個數「6」、∞ | `scale` 0.5 → 1 + `opacity` |
| **數線標記** | 倍數逐點亮起 | 每個 tick 漸顯 |
| **網絡圖建構** | 知識地圖中心輻射 | 中心 → 分支線 → 節點 三步逐顯 |

### 5.2 動畫節奏準則
- 單一動畫 duration：**0.5–1.5s**
- 階層延遲：每階 **0.4–0.6s**（太快來不及看、太慢失節奏）
- **動畫服務理解**：每個動畫都要能回答「這個動畫，讓學生更懂了嗎？」
- **動畫時間點對齊念到的字**：用 edge-tts 的 `WordBoundary` 取得每個詞的秒數，再把 tween 排在那個時間（GOTCHAS H-2）。不要憑感覺估
- 動畫結束後**靜止 1.5s 以上**讓學生消化——這同時是頁長（`data-duration`）的**第二個下限**，不能只照旁白長度訂。範本檔尾的分階動畫守衛會自動量，違規時 `npx --yes hyperframes@0.8.171 check` 失敗（見第 10 章步驟 8、GOTCHAS C-7）

### 5.3 ★ 關鍵動畫（每支影片至少 2–3 個）
這是 HF 的招牌時刻，必須做好：
- **數學結構建構**：因數樹、Venn 圖、座標系
- **知識地圖**：總結頁的中心輻射，把各概念連起來
- **步驟拆解**：方程式逐步展開

## 6. 數學內容規範

### 6.1 方程式必須用 KaTeX
```html
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.10/dist/katex.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/katex@0.16.10/dist/contrib/auto-render.min.js"></script>
```
用 `$...$` 行內公式。**KaTeX 的 CSS 不可寫成 `<link rel="stylesheet">` 或 `@import`**：HyperFrames 算繪時會把外部樣式表削成只剩 `@font-face`，公式會重複顯示兩次（GOTCHAS D-6）。改在檔尾用 JS 載入，載完、排版完、字型就緒才註冊時間軸：

```javascript
loadCss('https://cdn.jsdelivr.net/npm/katex@0.16.10/dist/katex.min.css').then(() => {
  renderMathInElement(document.getElementById('root'), {
    delimiters: [{ left: '$', right: '$', display: false }], throwOnError: false,
  });
  return document.fonts.ready;
}).then(() => { window.__timelines['main'] = tl; });
```
（`loadCss` 的寫法見範本 [`examples/02-factors-multiples/index.html`](../examples/02-factors-multiples/index.html) 檔尾。）

### 6.2 數學圖形
- **幾何圖**：用 `jh-math-geometry` 技能（已內建於 SOIL skill）或自繪 SVG
- **座標圖、函數圖**：SVG 手繪或呼叫 geometry_renderer
- **嚴格要求**：圖形比例正確、標籤位置不重疊、刻度均等

### 6.3 數學正確性檢查（強制）
產出後**逐頁檢查**：
- [ ] 方程式 LaTeX 語法正確
- [ ] 數字計算正確（自行算一遍）
- [ ] 幾何圖形比例符合題意（如「等腰三角形」就要真的等腰）
- [ ] 函數圖切線、漸近線符合定義
- [ ] 沒有把「⋯」誤打成「...」（中數字符要對齊）

## 7. 旁白規範

### 7.1 TTS（免費）
**zh-TW-HsiaoChenNeural**（女聲，預設）或 **zh-TW-YunJheNeural**（少年男聲）
參數：`--rate -10% --pitch -2Hz`

**語速依「新學」或「複習」決定**（使用者明確要求：複習快、新學慢）：

| 影片性質 | 建議 `RATE` | 理由 |
|---------|------------|------|
| **新學單元**（第一次學這個概念） | `-10%`（預設），念完留白 2～4 秒 | 學生要邊聽邊理解新名詞與步驟 |
| **複習**（已學過，課前／考前回顧） | `+35%`，念完留白 1～2 秒 | 學生已懂，慢速會拖沓；國一複習片從 -10% 被要求加快三次，使用者定案以 `+35%` 為複習語速 |

動工前就問這支片是新學還是複習，直接套對應語速與留白（`generate_narration.py` 的 `RATE`、`TAIL` 兩個常數；複習片改成 `RATE = "+35%"`、`TAIL = (1, 2)`，頁長用「旁白 + 約 1 秒」，動畫來不及跑完的頁再由守衛擋下加長）；事後改語速或換聲音，每頁旁白長度全變，時間軸要整支重排（GOTCHAS H-3）。

**備案：HyperFrames 內建 Kokoro TTS**（`python generate_narration.py --tts kokoro`）。本機執行、免網路、免金鑰，
但中文只有 `zf_xiaobei` 一個女聲、**中國口音**，且需另裝 `kokoro-onnx`（GOTCHAS H-1）。只在 Edge-TTS 連不上時用；
換引擎後每頁旁白長度都會變，要重看稽核表、重調頁長。

### 7.2 文案
- 每頁 1–4 句，**讀完 8–25 秒**
- **第二人稱「你」** 較不適用，**第三人稱口語講解** 為主
- 重點概念用「我們說：⋯」「注意，⋯」「這就是⋯」當口語錨點
- 避免照念投影片文字，要**補充**而非**重複**

### 7.3 旁白生成腳本（範本）
```python
import asyncio, edge_tts
VOICE = "zh-TW-HsiaoChenNeural"   # 預設女聲
async def synth(i, text):
    c = edge_tts.Communicate(text, VOICE, rate="-10%", pitch="-2Hz")
    await c.save(f"page-{i:02d}.mp3")

async def main():
    for i, t in SCRIPT:
        for r in range(3):
            try: await synth(i, t); break
            except: await asyncio.sleep(2)
```

> **重要**：必須**序列**執行，並行會被 Microsoft 端 reset connection。
> 範本的 `generate_narration.py` 已包含上面這段，外加 `--tts kokoro` 備案與時間軸稽核（第 8.3 節），直接 fork 使用。

**多音字與英文詞**：Edge-TTS 不能用 SSML 指定讀音，念錯就靠 repo 根目錄的 `tts-lexicon.tsv` 改字（例：奇數 → 基數、十一少一 → 十一少了一）。
`generate_narration.py` 產生旁白前自動替換，只影響送進 TTS 的文字，字幕照常寫正確用字（GOTCHAS H-4）。數學旁白常見的多音字（奇、少、數、還、差、重）寫完稿先對一次表。

### 7.4 字幕呈現
- 底部 30px 處，最大寬 88%
- `rgba(26,26,26,0.92)` 黑底白字，圓角 10px
- 字級 30px，font-weight 700（粗圓字仍清楚）
- 每頁的 `<section>` 裡放一條 `.subtitle`，跟著該頁一起出現、一起淡入
- **🔑 通則：單行 ≤ 25 字，以不換行為最大原則**（見 [GOTCHAS.md](../GOTCHAS.md) B-1）

## 8. 技術架構

### 8.1 專案結構
```
教學主題/
├── DESIGN.md                     # 套用本文件第 4 節即可，不必每次重寫
├── SCRIPT.md                     # 引擎 1-3 的產出 + 逐頁旁白
├── generate_narration.py         # 逐頁 TTS（Edge-TTS／--tts kokoro）+ 時間軸稽核
├── assets/
│   ├── fonts/                    # GenSekiGothic2TW-H/B/M.otf（每個專案自己一份，不進 git）
│   └── narration/                # page-01.mp3 ~ page-NN.mp3
├── final.mp4                     # npx --yes hyperframes@0.8.171 render 的產出
└── index.html                    # HyperFrames composition（主檔）
```

### 8.2 Composition 結構（HyperFrames 範式）
```html
<div id="root" data-composition-id="main" data-start="0"
     data-width="1920" data-height="1080" data-duration="244">   <!-- 總長 = 各頁加總 -->

  <section id="p01" class="slide clip" data-page="1" data-start="0"  data-duration="14">
    …版面… <div class="subtitle">字幕文字</div>
  </section>
  <section id="p02" class="slide clip" data-page="2" data-start="14" data-duration="25">…</section>

  <!-- 旁白：每頁一軌，時段和該頁相同；每個 <audio> 都要有 id -->
  <audio id="nar-01" src="assets/narration/page-01.mp3" data-start="0"  data-duration="14"></audio>
  <audio id="nar-02" src="assets/narration/page-02.mp3" data-start="14" data-duration="25"></audio>
</div>

<script>
const tl = gsap.timeline({ paused: true });
// S(n) 從標籤讀第 n 頁的 data-start；時間軸裡一律寫「頁起點 + 頁內秒數」
tl.fromTo(step(11, '.tree-node', 1), { opacity: 0 }, { opacity: 1, duration: 0.6 }, S(11) + 5.5);
// 刻意持續到頁尾的裝飾動畫加 data:'ambient'，分階動畫守衛才不會誤擋
tl.to('.infinity', { scale: 1.05, yoyo: true, repeat: 15, data: 'ambient' }, S(8));
// …分階動畫守衛（量每個 tween 的結束時間，見 GOTCHAS C-7）…
window.__timelines['main'] = tl;   // 有 KaTeX 時改成載完樣式才註冊（第 6.1 節）
</script>
```

**頁長的唯一真相來源是標籤上的 `data-start`／`data-duration`**，必須直接寫在 HTML 裡——HyperFrames 先靜態讀時間軸，
用 JS 事後設定它看不到（GOTCHAS D-3）。規則：`data-start` = 前一頁 start + duration；根節點 `data-duration` = 各頁加總；
每頁 `<audio>` 的時段與該頁相同。完整寫法直接看範本，不要從零寫。

### 8.3 渲染管線（與 #01、#03 共用）
```bash
python generate_narration.py          # 逐頁生成旁白 + 稽核時間軸（只改了頁長就加 --audit，不重跑 TTS）
npx --yes hyperframes@0.8.171 preview               # 瀏覽器預覽，存檔自動重新整理
npx --yes hyperframes@0.8.171 check                 # 出片關卡：必須顯示 Check passed
npx --yes hyperframes@0.8.171 render -o final.mp4   # 逐格算繪，1920×1080 30fps，旁白自動混音
```

- 不需要再組 master_audio、不需要 Playwright 錄影、不需要 ffmpeg mux——HyperFrames 一次做完。
- **一律用 `npx` 執行，不要在雲端硬碟上的專案裡 `npm install`**（GOTCHAS D-1）。第一次用先跑 `bash install/setup_hyperframes.sh`。
- `render` 不會替你擋缺檔（圖片 404 照樣出片），所以 `check` 不能省（GOTCHAS D-8）。

## 9. Do / Don't

### ✅ Do
- 先跑 SOIL 引擎 1-3 才動工，不要直接寫投影片
- 每頁有明確的教學任務
- 字級用 5 層階級，標題粗、內文清楚分層
- 動畫服務理解（每個動畫都能說明為什麼這樣動）
- KaTeX 渲染數學，不用圖片
- 旁白與字幕分層、不重複
- 內容填滿至少 80% 畫布
- 強調色 teal + coral 為主、gold 為輔

### ❌ Don't
- 不要把講義照搬上投影片
- 不要為了「精緻」加 drop shadow、玻璃感、漸層裝飾
- 不要單一頁面角色超過 1/4
- 不要動畫太花俏（旋轉、彈跳過頭）
- 不要把所有內容塞同一張投影片
- **不要犯數學錯誤**（比例、符號、計算）
- 不要旁白照念投影片文字
- 不要混搭多種字體（一致用源石黑體）
- 不要在 GDrive 內裝 node_modules（會壞掉；HyperFrames 一律用 `npx`）
- 不要用 CSS transition、`setTimeout`、`Math.random` 做動畫（算繪時不會動或每次不同，GOTCHAS D-5）

## 10. 給 agent 的執行 checklist

收到一份「教學影片」需求時，按此順序產出：

1. 確認 **學科 / 年級 / 單元 / 片長**（預設 4–6 分鐘）、**新學還是複習**（決定語速，見 7.1），以及**學生目前學到第幾冊第幾章**（例：「升國中前」「已升上國一」「要學第 1 冊第 2 章」開場與結尾預告完全不同，GOTCHAS A-4）、**語速**與**能不能暫停**
2. 跑 **SOIL 引擎 1**：產出概念定位稿 → **給使用者確認**
3. 跑 **SOIL 引擎 2**：產出脈絡定位稿（三段式）→ **給使用者確認**
4. 跑 **SOIL 引擎 3**：產出頁面架構表（含★關鍵動畫標記）→ **給使用者確認**
5. 建立 HyperFrames 專案：fork [`examples/02-factors-multiples/`](../examples/02-factors-multiples/)，**連同 `assets/fonts/`**
6. 撰寫 SCRIPT.md（每頁旁白 + 字幕）
7. 改 `generate_narration.py` 的 SCRIPT，跑 `python generate_narration.py` 序列生成 mp3
8. 依稽核表訂每頁 `data-duration`，取 **`max(旁白 + 2–4s tail, 動畫完成 + 1.5s)`**，兩個下限都要滿足。前者由 `generate_narration.py --audit` 擋（旁白超出頁長就 exit 1），後者由 `index.html` 檔尾的分階動畫守衛自動量（見 5.2、GOTCHAS C-7）
9. 寫 `index.html`（依本文件第 4–6 節風格 + KaTeX + SVG，動畫一律排在 GSAP 時間軸上）
10. **數學正確性自檢**（第 6.3 節清單）
11. `npx --yes hyperframes@0.8.171 preview` 給使用者看，`npx --yes hyperframes@0.8.171 check` 必須顯示 `Check passed`；再用 `npx --yes hyperframes@0.8.171 snapshot` 逐頁目視驗收（GOTCHAS D-10）
12. `npx --yes hyperframes@0.8.171 render -o final.mp4`
13. 給使用者預覽 → 確認後存檔
